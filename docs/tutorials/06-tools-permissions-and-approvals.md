# 工具、权限与审批

Sec 的工具通过函数签名生成输入 schema，调用前会校验模型提供的参数。CLI 默认提供：

| 工具 | 用途 |
|---|---|
| `read` | 读取工作区 UTF-8 文本文件 |
| `write`、`edit` | 创建/覆盖文件，或替换唯一匹配的文本 |
| `ls`、`find`、`grep` | 列出、查找和搜索工作区文件 |
| `bash` | 在工作区目录启动 Bash 命令 |

文件工具限制路径在配置的工作区内，并隐藏或拒绝访问 `.env`、密钥文件和常见凭据目录。读写和搜索也有限制文件大小、结果数和输出量。

## 权限模式

- `plan`：允许工作区只读工具，拒绝写入和执行。
- `normal`：对工具调用请求确认。
- `auto`：只自动允许工作区内置文件工具；Bash 和其他高风险工具仍需确认。

通过启动参数 `--mode` 或聊天命令 `/mode` 切换。`/trust on` 只在当前聊天期间切换到 `auto`，不是持久授权。

如果策略结果为 `ask`，SDK 会发出审批事件。宿主可用 `Trace.approve_tool(tool_call_id)` 或 `Trace.deny_tool(tool_call_id, reason)` 响应；拒绝不会调用工具执行器，而会将错误结果返回给模型。

## 安全边界

内置 Bash 使用当前操作系统用户权限，**不是沙箱**。路径限制不能限制 Bash 命令访问主机的其他资源。只启用可信工具和 Extension；不要把未经检查的模型输出直接当作 shell 命令执行。

非交互式 CLI 没有审批 UI，需要确认的工具调用会默认拒绝。有关自定义工具定义见[Extension 工具教程](12-extend-sec-with-tools-and-hooks.md)。
