## 使用方法

这些是生成行为与结果的验收规格，不是自动执行过的测试。修改skill后选受影响案例，提供输入与需求，检查生成说明、实际callable结果和真实Mint执行（环境可用时）。记录所用版本、确认回答、运行层级及结果；缺失依赖标为未运行。

以下数值仅是测试夹具，不是通用默认阈值。存在必须澄清项时，先验证是否提问，再给定回答继续。

| ID | 需求/输入夹具 | 预期行为或结果 |
|---|---|---|
| C01 | 保留entity_id,value并新增value_scaled | schema显式声明新列；输入不被意外原地修改 |
| C02 | 同entity的a1/a2账户，要求不同账户数；数据只提供实体键 | 指出粒度差异，不用实体去重冒充账户数 |
| C03 | 需要创建时间，但只有首次观测时间 | 确认代理授权；拒绝把观测时间声称真实创建时间 |
| C04 | 缺关系字段，用户授权扩展模板 | 声明字段类型、来源、键、有效期、缺失含义；缺列显式失败 |
| C05 | 描述“集中且相似”但无阈值 | 澄清或交付子指标，不从样例制造最终标签 |
| C06 | 用户把分方向统计更正为合并统计 | 更新所有受影响的已生成条目、说明和测试，而不只更新下一条 |
| T01 | D=2024-03-01，含当天最近2自然日，事件在02-28/02-29/03-01/03-02 | 只含02-29和03-01；含03-01晚间事件；不以末次事件03-02作锚点 |
| T02 | 监测[03-01,03-03)，基线紧前2天；事件02-27/02-28/02-29/03-01 | 基线只含02-28/02-29；不吞入所有旧历史 |
| T03 | 源窗口[10:00,11:00)，后续支持30分钟，源10:50、目标11:10 | 匹配成立，目标不扩大源分母；仅到11:00的数据需报告观察不足 |
| T04 | 同一时刻两个事件，无序号，要求严格先后 | 不凭ID字典序认定先后；按已确认策略排除或报歧义 |
| T05 | 夏令时切换日，要求当地自然日统计 | 保留当地日历边界，不无条件用24小时代替；明确时区 |
| N01 | 精确比较0.1与0.10；输入为十进制字符串 | 数值相等，未先转换float丢精度；输出精度单独说明 |
| N02 | 基底10，整数倍≥2，绝对容差1，观测19/20/21/21.01 | 前三者合格、最后不合格；检测不能仅向下取整 |
| N03 | 候选基底10/20，观测10/20/20/40，不计1倍 | 基底10匹配3笔、实际合计80；重复值按频数还原 |
| N04 | 转换因子缺失，或数值NaN/无穷 | 不默认为1/0；按质量契约报错或报告排除及分母影响 |
| M01 | FIFO源S1=6、S2=4，随后目标T1=8、T2=5，均在窗口内 | 分配总额10，S1/S2各计一次，T2未分配3，无负剩余量 |
| M02 | S1可匹配T1/T2，S2只可匹配T1 | 标明贪心可能1对，最大匹配可2对；不能混淆算法目标 |
| J01 | 一条事件value=10，右侧同键两行，期望多对一 | 在求和前识别基数异常，不能输出20还称正确富化 |
| J02 | 版本v1有效[01-01,02-01)，v2有效[02-01,03-01)，事件02-01 | 只选v2；版本重叠报错/明确处理，无有效版本保持质量状态 |
| G01 | 主体ID与资源ID都为"x" | 类型命名空间隔离，不意外合并节点 |
| G02 | 三实体共用公共资源，生成连通分量 | 输出候选关联并披露公共资源影响，不声称已证实群体 |
| G03 | 两条候选路径共享同一事件边 | 不直接把路径数值和当独立事件总量；说明复用 |
| V01 | 空输入、完整源中无事件实体、全缺失数值组 | 三种情况独立处理，不一律输出0/False；覆盖输出schema |
| V02 | Mint缺失，仅直接运行callable | 报告callable验证通过、Mint集成未运行，不伪造全通过 |
| V03 | nullable bool、date、嵌套list输出 | 静态字段匹配不足；真实Mint结果消费验证转换与空值 |
| B01 | 3条需求第2条待确认，第1条已有用户代码 | 保留用户代码，独立条目可继续，报告待确认项 |
| B02 | 第一批保存后中断、源文件又被用户修改 | 续做读取最新状态，冲突不覆盖，已完成内容不重复追加 |
| B03 | 目标单元格代码超过适配器限制 | 显式报告并选择拆分/外部交付，不静默截断 |

验收至少同时检查：是否选择正确生成模式、是否遵守确认口径、输出数值/形状是否符合预期、是否诚实报告验证与交付状态。
