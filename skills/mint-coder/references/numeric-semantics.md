## 单位先于运算

确认原单位、目标单位、转换因子方向及其时间有效性。不同单位的原值不能直接求和或比较。转换因子缺失不能自动取1；是否允许负数、零值取决于数据契约，不是所有数值都必须正数。

一般流程：筛选目标记录 → 验证原值和转换因子 → 按约定精度转换 → 聚合 → 判定 → 序列化。转换前后舍入顺序会影响结果，需写清。

## 数值模型

| 模型 | 适用与限制 |
|---|---|
| 整数最小单位 | 固定小数位、精确计量；声明缩放因子和整数溢出范围 |
| Decimal | 十进制精确规则；明确上下文精度和舍入方式，不先经过float再声称精确 |
| float | 连续测量或近似统计；误差模型需约定，边界比较注意表示误差 |

`Decimal(str(float_value))` 不会恢复 float 之前丢失的精度。Decimal 的精度应满足值域与运算链，不能把某次任务的精度位数设成无条件通用默认。

精确结果输出为 `double` 会再次产生表示误差；在输出前完成精确判定，并披露输出近似性。Mint decimal schema 等未被当前文档/运行版本验证的类型不能自行编造。

验证有限值、值域、参数范围、转换后溢出。合法缺失与非法字符串区分；NaN/无穷不能参与有意义的阈值判定。

## 相等与误差

- 精确相等：明确是否按规范化后的十进制值、原始值或量化值比较。
- 绝对误差：`abs(observed-expected) <= atol`，容差单位与值相同。
- 相对误差：例如 `abs(observed-expected) <= rtol*abs(expected)`，明确以哪个值为参照。
- 混合误差：例如 `abs(observed-expected) <= atol+rtol*abs(expected)`；这不等于所有库函数的默认公式。
- 参照为0时相对误差无有效尺度；需绝对容差或独立规则。

边界是否包含、容差值、量化位数不可由样例擅自推断。不把容差用作清洗非法输入的手段。

## 通用倍数搜索契约

明确候选基底来源、最低有效值、允许整数/分数倍、倍数范围、是否包含1倍、计数对象、重复记录处理及误差。

对正基底b和观测x，查找允许倍数中使 `abs(x-b*k)` 最小的k；不能只用向下取整判断，可能漏掉接近上一个倍数的值。限制整数k≥K时，考虑边界K及商附近候选；1倍是否排除是业务口径。

输出可包括基底、匹配记录数、实际观测值总和、误差摘要。不要用 `b*k` 理论值总和冒充实际匹配值总和。并列采用明确规则；无匹配时基底通常未知，数量可为0，但需契约确认。

按唯一值预聚合频数可减少重复比较，但计数/总和必须用频数还原。U个不同值的两两搜索约O(U²)，不因使用频数表就宣称线性。

验证：容差内/边界/外、接近上下两个倍数、最低基底边界、重复值计数、并列、无匹配、极大数值及不同单位。
